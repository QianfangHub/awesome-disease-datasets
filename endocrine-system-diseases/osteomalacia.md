# 骨软化症 · Osteomalacia — Top 31 Datasets

> 所属系统 / System：**[内分泌系统疾病 Endocrine System Diseases](../README.md)**

> 分类定义 / Definition：骨软化症是一种以骨基质矿化障碍为特征的代谢性骨病，主要因维生素D缺乏或代谢异常导致骨骼钙化不足，骨组织内类骨质大量堆积，骨强度显著降低。典型临床表现为弥漫性骨痛、肌无力、鸭步步态及易于发生假性骨折，严重时可出现骨骼畸形。实验室检查常显示低钙血症、低磷血症、碱性磷酸酶升高及25-羟维生素D水平降低，影像学可见假骨折线（Looser带）和骨密度减低。治疗以补充维生素D、钙剂及针对原发病因干预为主，大部分患者预后良好。该病在临床数据平台中常作为代谢性骨病专病队列的核心病种，对于骨折风险预测、营养干预研究和疾病监测模型构建具有重要价值。
>
