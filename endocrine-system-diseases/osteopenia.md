# 骨质减少 · Osteopenia — Top 31 Datasets

> 所属系统 / System：**[内分泌系统疾病 Endocrine System Diseases](../README.md)**
>
> 分类定义 / Definition：骨质减少是一种以骨矿物质密度降至低于正常峰值骨量但尚未达到骨质疏松症诊断标准为特征的代谢性骨病，通常定义为双能X线吸收法测得的T值在-1.0至-2.5之间。该状态由骨转换失衡所致，破骨细胞骨吸收活性相对增强，成骨细胞骨形成功能不足，导致骨量持续丢失。多数患者无明显症状，但骨折风险已显著升高，常见于绝经后女性及老年人。临床诊断主要依赖骨密度测量与骨折风险评估工具，管理策略包括调整生活方式、足量钙与维生素D摄入、负重运动及控制危险因素；高危个体可考虑药物干预。骨质减少是骨质疏松症的重要预警阶段，早期识别与干预对延缓骨质流失、降低脆性骨折发生率具有关键意义。
>
> *Osteopenia is a skeletal condition defined by bone mineral density (BMD) lower than expected peak bone mass, with a T-score between −1.0 and −2.5 on dual-energy X-ray absorptiometry, representing an intermediate state between normal bone density and osteoporosis.
