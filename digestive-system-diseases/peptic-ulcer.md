# 消化性溃疡 · Peptic ulcer — Top 10 Datasets

> 所属系统 / System：**[消化系统疾病 Digestive System Diseases](../README.md)**

> 分类定义 / Definition：消化性溃疡是指发生于胃和十二指肠的慢性溃疡，主要由胃酸和胃蛋白酶对黏膜的自身消化引起，幽门螺杆菌感染和非甾体抗炎药使用是其主要危险因素。该病典型表现为慢性、周期性、节律性上腹痛，可伴有反酸、嗳气等症状，严重时可并发出血、穿孔、幽门梗阻甚至癌变。诊断依靠胃镜及黏膜活检，治疗以抑制胃酸、根除幽门螺杆菌和保护胃黏膜为主。在临床数据平台与科研数据库中，消化性溃疡是消化道疾病精准管理的重要专病类型，其诊疗路径、并发症监测和长期随访数据对优化治疗策略具有关键价值。
>
