# 假性肠梗阻 · Intestinal pseudo-obstruction — Top 10 Datasets

> 所属系统 / System：**[消化系统疾病 Digestive System Diseases](../README.md)**
>
> 分类定义 / Definition：假性肠梗阻是一种以严重肠道动力障碍为特征的临床综合征，患者出现腹胀、腹痛、恶心呕吐、排便排气停止等机械性肠梗阻样表现，但影像学与手术探查均未发现器质性狭窄或阻塞。其核心发病机制为肠道神经肌肉病变或功能异常导致的无效推进运动，可急性发作或呈慢性病程，常见诱因包括腹部手术、感染、代谢紊乱及结缔组织病等。诊断需首先排除机械性梗阻，并借助影像学、肠道动力学检查等综合评估。治疗以支持治疗为主，包括胃肠减压、纠正水电解质紊乱、营养支持及促动力药物，重症慢性患者可能需要手术造口或小肠移植。在医学知识图谱与临床数据库中，该病作为功能性胃肠病的典型实体，为罕见病鉴别与专病队列研究提供关键节点。
>
