# 结肠动力障碍 · Colonic dysmotility — Top 4 Datasets

> 所属系统 / System：**[消化系统疾病 Digestive System Diseases](../README.md)**
>
> 分类定义 / Definition：结肠动力障碍是一类以结肠推进性收缩功能异常为核心特征的慢性胃肠动力疾病，主要包括慢传输型便秘和结肠无力症。其发病机制涉及肠神经系统异常、Cajal间质细胞减少、神经递质失衡及平滑肌功能障碍，导致结肠内容物通过时间显著延长。临床上以顽固性便秘、排便费力、便意缺失和腹胀为主要表现，常需排除机械性梗阻及药物性因素。诊断依赖结肠传输试验、肛门直肠测压及排粪造影等检查。治疗遵循阶梯式策略，涵盖饮食调整、促动力药物、生物反馈治疗，对难治性患者可考虑骶神经调控或手术切除无功能肠段。该病是功能性胃肠病和盆底障碍研究的重要方向。
>
