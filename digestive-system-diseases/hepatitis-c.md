# 丙型肝炎 · Hepatitis C — Top 4 Datasets

> 分类定义 / Definition：丙型肝炎是由丙型肝炎病毒（HCV）感染引起的病毒性肝炎，主要通过血液传播，可导致慢性肝脏炎症、肝纤维化、肝硬化及肝细胞癌。急性感染时多数患者无明显症状，或仅表现为乏力、食欲减退，部分可自发清除病毒；约55%~85%会进展为慢性感染，潜伏期长且隐匿进展。慢性丙型肝炎的治疗已进入直接抗病毒药物（DAA）时代，可实现超过95%的持续病毒学应答，显著降低肝硬化和肝癌风险。目前尚无有效疫苗，全球范围内仍是导致肝移植及肝脏相关死亡的重要原因之一。
>
