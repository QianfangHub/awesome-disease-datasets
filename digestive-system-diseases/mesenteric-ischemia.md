# 肠系膜缺血 · Mesenteric ischemia — Top 18 Datasets

> 所属系统 / System：**[消化系统疾病 Digestive System Diseases](../README.md)**

> 分类定义 / Definition：肠系膜缺血是由肠系膜动脉或静脉血流障碍引起的肠道血液灌注不足性急症，主要包括急性肠系膜动脉栓塞、血栓形成、非闭塞性肠系膜缺血及肠系膜静脉血栓形成等亚型。病理核心为肠壁缺血缺氧，若未及时恢复灌注，可迅速进展为肠坏死、穿孔及脓毒症。急性典型表现包括剧烈腹痛与体征不相称、恶心呕吐、血便及代谢性酸中毒；慢性肠系膜缺血则以餐后腹痛、畏食和体重下降为特征。诊断首选CT血管成像及肠系膜血管造影，生生物标志物如D-二聚体、血清肠脂肪酸结合蛋白有辅助价值。治疗路径涵盖液体复苏、血管内介入治疗（如导管溶栓、支架植入）、开放取栓或肠切除手术。当前研究聚焦于快速决策评分系统、多模态影像评估及缺血再灌注损伤保护策略。
>
