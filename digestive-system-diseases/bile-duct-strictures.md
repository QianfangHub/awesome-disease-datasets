# 胆管狭窄 · Bile duct strictures — Top 22 Datasets

> 所属系统 / System：**[消化系统疾病 Digestive System Diseases](../README.md)**
>
> 分类定义 / Definition：胆管狭窄指各种原因导致的肝内外胆管管腔局限性或弥漫性变窄，是肝胆外科和消化内科常见的病理状态。其发病机制主要包括良性因素（如医源性损伤、慢性胰腺炎、原发性硬化性胆管炎）和恶性因素（如胆管癌、胰头癌压迫），造成胆汁引流障碍及继发性胆管扩张。典型临床表现为梗阻性黄疸、右上腹疼痛、发热和皮肤瘙痒，长期狭窄可致胆汁性肝硬化。诊断依赖磁共振胰胆管成像、内镜逆行胰胆管造影及超声内镜，治疗以解除梗阻为核心，良性狭窄多采用内镜下球囊扩张或支架置入，恶性狭窄常需外科切除或姑息性引流。该病是胆道疾病精准诊疗和临床数据平台建设的重要关注对象。
>
